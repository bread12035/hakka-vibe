# 15: 彙總報告

**What to build:** 將 24 個 arm、72 次 run 的結果整理成一份可據以決策的報告：哪些 harness 手段真的省錢、省多少、實作成本如何，以及哪些結論不可外推。這份報告的結論將決定後續 agent layer 與 MemoryStore 的設計。

**Blocked by:** 06, 08, 09, 10, 11, 12, 13, 14

**Status:** ready-for-agent

- [ ] 24 個 arm 的成本對照，一律以美元表述，token 細項作為診斷資料附列
- [ ] 兩個 harness 的百分比分開呈現，並說明 TTL 不同使其單價基準不同
- [ ] 各 arm 的中位數與最大最小值並列，變異幅度本身視為結果
- [ ] 明載限制：所有數字建立在合成 fixture 之上，arm 之間的相對差異可信，絕對值不可外推至真實專案
- [ ] 明載生成 fixture 與解題模型同屬一個模型家族所構成的效度威脅
- [ ] 依成本節省與實作成本的比值排序，指出下一步最值得投入的方向
