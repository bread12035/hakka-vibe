# Issues

本專案的 issue tracker。spec 與票都是這裡的 markdown 檔，跟著 code 一起進版控。

```
docs/issues/
└── <feature-slug>/
    ├── spec.md                  ← /to-spec 產出
    └── issues/
        ├── 01-<slug>.md         ← /to-tickets 產出
        └── 02-<slug>.md
```

慣例（`Status:` 值、`Blocked by:` 寫法、`## Comments` 區塊）定義在 `docs/agents/issue-tracker.md`。
